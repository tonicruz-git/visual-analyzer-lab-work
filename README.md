# 📊 Visual Analyzer

> **Interactive Multi-Dimensional Data Visualization Dashboard**

**Visual Analyzer** transforms CSV datasets into interactive dashboards with real-time filtering, schema inference, and customizable charts.

### ✨ Features
* **Universal CSV Ingestion:** Upload custom files, paste raw CSV text, or explore built-in curated datasets.
* **Real-Time Cross-Filtering:** Search across records, dial in numeric range sliders, or click chart elements to filter data instantly.
* **Multi-Chart Customizer:** Build and fine-tune Bar, Line, Area, Scatter, Donut, Histogram, Radar, Heatmap, and KPI cards.
* **Data Grid & Profiler:** Examine raw records with sortable columns, pagination, and instant column statistical summaries.
